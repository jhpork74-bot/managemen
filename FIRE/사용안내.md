# 복지관 FIRE MISSION

Google 스프레드시트 + Apps Script용 모바일 소방 체험 게임입니다. `1층도면.skp`, `2층도면.skp`를 설치된 SketchUp 2019 C API로 읽고, 바닥 높이(Z=0)의 벽 면을 25cm 격자로 변환했습니다. 원본 SKP는 수정하지 않았습니다.

## 바로 확인

`preview.html`을 브라우저로 열면 로컬 체험이 가능합니다. 기본 소화기·계단·시작 위치가 포함되어 있습니다. 브라우저에 따라 파일 URL의 저장소 접근이 제한되면 아래 로컬 서버를 이용하세요.

```powershell
node .\tools\serve.cjs
```

그다음 http://127.0.0.1:8787 에 접속합니다. 로컬 체험에서는 설정이 해당 브라우저에만 저장되며 Google Sheets에는 기록되지 않습니다.

## Google Sheets 배포

1. 새 Google 스프레드시트를 만들고 **확장 프로그램 → Apps Script**를 엽니다.
2. `Code.gs` 내용을 붙여넣습니다.
3. HTML 파일을 각각 `Index`, `Maps`, `Engine3D`라는 이름으로 만들고 같은 이름의 HTML 파일 내용을 붙여넣습니다. 기존 프로젝트에도 **Engine3D HTML 파일을 새로 추가**해야 합니다. 파일 이름은 대소문자를 구분합니다.
4. 프로젝트 설정에서 매니페스트 파일 표시를 켜고 `appsscript.json` 내용을 반영합니다.
5. 함수 목록에서 `setup`을 한 번 실행하고 Google 권한 요청을 승인합니다. 키 입력은 필요하지 않습니다.
6. **배포 → 새 배포 → 웹 앱**을 선택합니다. 실행 사용자는 **나**, 접근 사용자는 체험 대상과 조직 정책에 맞게 설정합니다. 배포된 `/exec` URL을 엽니다.
7. **관리자** 탭에서 실제 소화기와 계단 위치를 확인·수정하고 **설정 저장**을 누릅니다. 최초 저장 전에는 온라인 입장이 제한됩니다.
8. 참가자에게 웹 앱 URL 또는 해당 URL의 QR코드를 제공합니다. 휴대폰은 같은 URL에 접속합니다. PC의 `127.0.0.1` 주소는 다른 휴대폰에서 접속할 수 없습니다.

`Settings`에는 지도 설정 JSON이 저장되고, `Records`에는 완료시각·이름·소요초·결과·세션이 저장됩니다. `Sessions`는 서버 시작시간과 중복 완료 방지에 사용됩니다. `setup`을 다시 실행해도 기존 설정과 기록을 삭제하지 않습니다. 소스 변경 후에는 배포 관리에서 새 버전으로 업데이트해야 합니다.

## 관리자 사용

- **방 출입구**: 방 목록에서 방을 선택한 뒤 **방 출입구** 도구로 실제 문 통로를 클릭하고 설정 저장합니다. 3D에서 해당 위치의 높이 2.2m에 방 이름 표지판이 표시됩니다. 수동 지정이 없으면 방에서 입장 기준점으로 가는 길의 좁은 통로를 출입구 후보로 사용합니다. 자동 후보는 실제 출입구와 다를 수 있으므로 관리자에서 확정해주세요. 2D 편집 화면에서는 지정된 출입구가 문 아이콘으로 표시됩니다.

- **전체 보기 옆 맵 다시로드**를 누르고 관리자 **설정 JSON 내보내기**로 저장한 파일을 선택하면 기존 맵 설정을 덮어씁니다. 배포된 웹 앱에서는 Google 스프레드시트에 바로 저장하고 다시 불러오므로 별도의 설정 저장 클릭은 필요 없습니다. 소화기·계단·방 이름·벽 보정이 함께 반영됩니다. 로컬 미리보기에서는 해당 브라우저에만 저장됩니다. 미션 중에는 사용할 수 없으며, JSON 형식이나 이동 경로가 잘못되면 기존 설정을 유지합니다. 원본 SKP 면 좌표 JSON이나 `data/maps.json`이 아닌 **설정 JSON**을 사용하세요.
- 캐릭터는 제공한 소방관 사진과 헬멧 중앙의 119 마크를 합성한 이미지입니다. 이미지가 `Index.html`에 내장되어 별도 이미지 서버가 필요 없습니다. 캐릭터·소화기·불은 겹쳐도 불투명하게 표시하고 캐릭터를 가장 위에 그립니다.

- 상단 1층/2층으로 편집할 층을 선택합니다.
- 소화기 도구로 통로를 누르면 배치되고, 같은 위치를 다시 누르면 삭제됩니다.
- **방 이름** 도구를 선택하고 텍스트박스에 이름(최대 30자)을 입력한 뒤 지도에서 방 중앙을 누르면 이름표가 배치됩니다. 기존 이름표 또는 아래 방 목록을 선택한 뒤 **선택한 이름 수정**이나 **삭제**를 사용할 수 있습니다. 방 이름은 설정 저장 시 스프레드시트에 함께 저장되고 참가자 지도에도 표시됩니다.
- 방 이름 도구에서 마우스를 지도 위로 움직이면 입력한 이름이 깜박이는 네모로 따라다닙니다. 초록색은 배치 가능한 곳, 빨간색은 벽 등 배치할 수 없는 곳입니다. 클릭 전에는 저장되지 않으며, 설정 저장 후에도 입력한 이름을 계속 미리 볼 수 있습니다.
- 계단은 각 층에 한 곳씩 배치합니다. 이 두 위치가 연결됩니다. 기본 위치는 오른쪽 계단 부근의 임시 배치이며 현장과 대조해야 합니다.
- 입장 위치는 전체 게임에 한 곳입니다.
- 확대/축소 버튼과 지도 드래그로 작은 위치를 조정할 수 있습니다.
- **벽 보정 → ㅡ 가로 / ㅣ 세로**를 선택하고 지도에서 시작점과 끝점을 차례로 클릭하면 사이를 직선 벽으로 연결합니다. 가로는 시작점의 높이에, 세로는 시작점의 좌우 위치에 맞춥니다. 클릭 전 노란색으로 구간이 미리 표시됩니다. **시작점 취소**로 다시 선택할 수 있습니다. 기존 소화기·계단·입장 위치·방 이름을 가로지르는 구간은 위치를 옮겨야 생성할 수 있습니다.
- **벽 보정 → 지우개**를 선택하면 마우스에 50×50px 박스가 표시됩니다. 클릭하거나 누른 채 드래그하면 박스와 겹치는 벽 칸이 지워집니다. 박스는 지도 확대율에 관계없이 화면 기준 50px이며, 마우스를 올리기만 하면 지워지지 않습니다. 원본 도면의 벽과 추가한 벽 모두 지울 수 있고, 소화기·계단·방 이름은 지워지지 않습니다. 변경 후 **설정 저장**을 누르세요.
- 문이 격자 변환 과정에서 막혔다면 **통로 보정**으로 열고, 이동을 막을 부분은 **벽 보정**으로 지정합니다. 외부 공간이나 출입 제한 구역도 벽 보정으로 막을 수 있습니다.
- 소화기와 계단까지 경로가 연결되지 않으면 저장이 거절됩니다.
- **설정 저장**이 성공해야 다음 참가자에게 반영됩니다. 이미 진행 중인 미션에는 시작 시점의 설정이 적용됩니다.
- JSON 내보내기/가져오기로 배치를 백업할 수 있습니다. 가져온 뒤 저장 버튼을 눌러야 서버에 반영됩니다.

## 게임 조작

- **3D 화면 / 2D 화면** 버튼으로 화면 방식을 전환합니다. 관리자는 항상 2D 지도로 편집합니다. 3D 벽체는 같은 `cfg.edits`가 적용된 격자에서 생성되며 맵 다시로드나 설정 저장 내용이 반영됩니다.
- 3D는 소방관을 뒤에서 따라가는 시점입니다. **위: 전진 / 아래: 후진 / 좌우: 회전**, 화면 드래그로 시선을 회전합니다. 이동 시 팔·다리가 움직이고, 장비를 획득하면 들고 있는 장비를 표시합니다. 2D에서는 기존 화살표 방향 이동이 유지됩니다.
- 벽·천장 높이는 **2.8m**입니다. 흰색 텍스 천장, 나무무늬 벽 시트지, 갈색 줄눈의 노란 타일 바닥은 코드로 생성한 질감입니다. 3D 소방관은 기존 캐릭터 색상과 장비에 맞춘 단순 입체 모델이며, 2D와 미니맵에는 원래 PNG를 사용합니다.
- 화재 모드에서는 제한시간의 약 70%가 지날 때까지 천장 부근의 회색 연기가 점차 짙어집니다. 심정지 모드는 연기나 천장 변화가 없습니다. 연기는 시각 효과이며 화재 확산·연기 유동을 계산하는 물리 시뮬레이션은 아닙니다.
- 오른쪽 아래 정사각형 미니맵에 현재 층의 전체 지도·캐릭터·장비·발생 위치·경로가 표시됩니다. 3D를 지원하지 않는 기기에서는 2D로 전환합니다. 실제 휴대폰 성능은 기기에 따라 다릅니다.

- 입장 전에 **미션 선택** 드롭다운에서 **화재 / 심정지**를 선택합니다. 진행 중에는 변경할 수 없습니다.
- 심정지는 관리자에서 **♥ AED** 도구로 AED를 배치하고 설정 저장한 뒤 시작합니다. 위치를 다시 클릭하면 AED가 삭제됩니다. 환자 위치와 시작 위치는 무작위이며, 환자에서 이동 거리가 가장 짧은 AED로 안내합니다. **AED 옆 E → 환자까지 이동 → 환자 옆 E** 순서로 완료합니다. 소화기로 심정지 미션을 완료할 수 없습니다.
- 심정지의 환자 표시는 분홍색, AED는 초록색 하트와 AED 글자로 표시합니다. 지정 AED에는 초록 테두리가 표시됩니다. 이 모드는 AED 운반 경로 체험이며 실제 AED 조작 단계는 구현하지 않습니다.
- 신규 버전 설치 후 `setup`을 다시 실행하면 기존 데이터는 유지하고 Records와 Sessions에 미션 종류 열 제목을 추가합니다. 기록에는 화재/심정지가 구분되어 저장됩니다.

- **입장**: 이름 입력 후 시작. 이동 가능한 연결 영역에서 시작 위치와 화재 위치를 각각 무작위 선택합니다. 관리자 입장 위치는 무작위 선택을 위한 연결 영역의 기준점입니다.
- 게임 시작 직후 화면 중앙에 화면 너비 약 40% 크기의 **불이야!** 문구가 2초간 표시됩니다. 표시 중에도 미션 시간과 조작은 계속됩니다.
- PC: **화살표**로 이동, **E**로 행동.
- 모바일: 화면 방향 버튼을 누르고 있으면 연속 이동, 둥근 **E** 버튼으로 행동.
- 화재 모드에서는 시작점에서 화재로 가는 최단 이동 경로를 확인하고, 그 경로에서 처음 만나는 소화기(같은 칸 또는 바로 옆)를 먼저 안내합니다. 획득하지 않고 그 지점을 지나 화재 쪽으로 더 이동하면 화재에서 실제 이동 거리가 가장 짧은 소화기로 안내를 전환합니다. 첫 동선에 소화기가 없으면 처음부터 화재와 가장 가까운 소화기를 안내합니다. 초록 테두리의 지정 소화기 옆에서 E로 획득하세요. 심정지 모드의 AED는 계속 환자와 가장 가까운 AED를 안내합니다.
- 계단 바로 옆 또는 같은 칸에서 E로 다른 층으로 이동합니다.
- 소화기를 가진 상태에서 화재 바로 옆 또는 같은 칸에서 E로 진압합니다.
- 점선은 무작위 시작점에서 지정 소화기까지, 획득 후에는 화재까지의 최단 이동 경로입니다. 층을 넘는 경로는 계단을 이용합니다. 계단 표시는 화면 기준 50×50px이고, 실제 층 이동은 표시 중앙의 계단 칸 옆에서 E로 수행합니다. 소화기와 화재 표시는 기존의 2배 크기입니다.
- 벽은 통과할 수 없습니다. 캐릭터 주변을 가리는 벽은 반투명으로 표시됩니다.
- 제한시간과 실제 완료 소요시간을 표시하며, 온라인에서는 서버 시간 기준 기록을 저장합니다. 저장 실패 시 **기록 저장 재시도**를 누르세요.

## 구현 범위와 확인할 점

2D 지도는 Canvas, 3D는 외부 라이브러리 없이 WebGL로 렌더링합니다. SKP에서 추출한 벽 평면을 2.8m 높이로 세운 공간이며 원본 SketchUp의 모든 문·가구·창호를 재현한 모델은 아닙니다. 2D 캐릭터는 헬멧 중앙에 119 마크를 넣은 투명 PNG를 사용합니다.

1층은 158×70, 2층은 154×70 격자입니다. 벽은 실제 SKP 면에서 추출했지만, 소화기 위치나 층간 계단의 의미를 파일에서 자동 인식한 것은 아닙니다. 기본 배치를 현장과 확인하고, 작은 문·외부 경계·계단의 진입 칸은 관리자 보정으로 최종 확정하세요. 경로는 게임 격자상의 경로이며 실제 피난 경로 인증을 의미하지 않습니다.

요청에 따라 관리자 키를 제거했습니다. 웹 앱에 접속 가능한 사람은 관리자 탭에서 설정을 저장할 수 있습니다. 이 게임은 교육 체험용으로 완료 판정을 클라이언트에서 수행하므로 상금 경쟁용 부정행위 방지 기능은 포함하지 않습니다.

이 환경에서 Google Apps Script 프로젝트 생성·배포를 실행할 연결 도구가 없어 **Google 웹 앱 배포와 실제 Google Sheets 입출력은 미검증**입니다. 위 절차로 계정에서 배포해야 공유 플레이와 서버 저장이 작동합니다.

## 개발 파일

- `Index.html`: 게임, 관리자 화면, 조작 및 경로 탐색
- `Maps.html`: 실제 도면 격자와 기본 배치
- `Code.gs`: 설정 저장, 세션 및 결과 기록
- `data/floor1-faces.json`, `floor2-faces.json`: 원본 SKP에서 추출한 면 좌표(인치)
- `tools/extract.ps1`: 설치된 SketchUp 2019 API를 통한 읽기 전용 추출
- `tools/build.cjs`: 지도 및 로컬 미리보기 생성
- `tools/test.cjs`: 경로·충돌·계단·설정 검사

검사 실행: `node tools/test.cjs`

API 구현 근거: [Apps Script 웹 앱](https://developers.google.com/apps-script/guides/web), [클라이언트와 서버 통신](https://developers.google.com/apps-script/guides/html/communication), [SketchUp Entities API](https://extensions.sketchup.com/developers/sketchup_c_api/sketchup/struct_s_u_entities_ref.html).
