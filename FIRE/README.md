# FIRE — 복지관 안전 체험 게임

Google Sheets + Apps Script에서 실행하는 2D/3D 화재·심정지 미션입니다.

## 설치할 파일

| 파일 | Apps Script의 파일 이름 |
|---|---|
| Code.gs | Code |
| Index.html | Index (HTML) |
| Maps.html | Maps (HTML) |
| Engine3D.html | Engine3D (HTML, 신규 필수) |
| appsscript.json | 프로젝트 매니페스트 |

스프레드시트 → 확장 프로그램 → Apps Script에서 위 파일을 추가하고 `setup` 실행 후 웹 앱으로 배포하세요. 기존 배포는 파일 교체와 Engine3D 추가 후 배포 관리에서 **새 버전**으로 갱신합니다. HTML 파일은 브라우저로 연 화면이 아닌 텍스트 편집기로 열어 전체 소스를 복사하세요.

관리자의 설정 JSON에는 소화기·AED·계단·방 이름·출입구·벽 보정이 저장됩니다. 운영 스프레드시트 ID나 개인별 설정은 이 저장소에 포함하지 않습니다. 최초 배포 후 관리자 설정 저장이 필요합니다. 기존 미리보기의 배치를 옮기려면 설정 JSON 내보내기 → 배포 웹 앱의 맵 다시로드로 가져오세요.

## 3D

- 3인칭 소방관 및 걷기/달리기 동작, 2D 전환
- 벽 높이 2.8m, 흰 텍스 천장, 나무무늬 벽, 갈색 줄눈 노란 타일
- 화재에서만 시간에 따라 천장 연기 증가
- 우측 하단 전체 미니맵, 관리자 지도와 동일한 벽/장비 데이터
- 출입구 위 방 이름 표지판: 관리자에서 방 선택 → 방 출입구 → 지도 클릭

화살표 위/아래는 전진/후진, 좌우는 회전, 드래그는 시선 변경, E는 행동입니다. 모바일은 화면 버튼을 사용합니다. 실제 AED 조작이나 화재 대응 절차 전체를 훈련하는 시뮬레이터는 아니며 이동 경로 체험 게임입니다.

## 로컬 실행 / 검사

Node.js가 있는 PC에서 이 폴더를 연 뒤:

```text
node tools/serve.cjs
```

http://127.0.0.1:8787 에 접속합니다. 로컬 미리보기는 브라우저 저장소를 사용합니다.

```text
node tools/build.cjs
node tools/test.cjs
node tools/test-server.cjs
```

자세한 내용은 [사용안내.md](사용안내.md)를 참고하세요. 테스트는 로컬 로직과 모의 Google 서비스 검사이며, Google 실제 배포 및 실제 휴대폰 검증은 별도입니다.
