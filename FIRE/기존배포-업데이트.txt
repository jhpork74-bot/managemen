최신 수정본 적용 방법

1. 압축을 풀고 기존 Google 스프레드시트의 확장 프로그램 > Apps Script를 엽니다.
2. Code.gs, Index.html, Maps.html 파일 내용을 각각 이 ZIP의 파일 내용으로 모두 교체합니다.
   새 HTML 파일 Engine3D를 추가하고 Engine3D.html의 전체 소스를 붙여넣습니다.
   HTML 파일 이름은 Index, Maps, Engine3D입니다. 세 파일을 모두 반영하세요.
3. appsscript.json도 함께 확인하고 저장합니다.
4. 기존 프로젝트에서 setup을 이미 실행했다면 다시 실행할 필요 없습니다.
5. 배포 > 배포 관리 > 현재 웹 앱 선택 > 수정(연필)을 누릅니다.
6. 버전에서 '새 버전'을 선택한 뒤 배포를 누릅니다.
7. 기존 /exec 웹 앱 주소를 다시 열고 새로고침합니다.

미리보기의 소스 수정은 배포된 Apps Script 파일을 자동으로 변경하지 않습니다.
또한 미리보기에서 지정한 소화기, 방 이름, 벽 보정 설정은 브라우저에 저장됩니다.
이 설정도 옮기려면 아래 절차가 추가로 필요합니다.

1. 로컬 미리보기 > 관리자 > 설정 JSON 내보내기
2. 배포한 웹 앱 > 관리자 > 설정 JSON 가져오기
3. 가져온 지도 확인 > 설정 저장

코드 업데이트와 지도 설정 이전은 별도입니다.
이 ZIP에는 최신 코드와 기본 배치가 포함되며, 브라우저에 따로 저장한 사용자 편집 설정은 자동 포함되지 않습니다.

포함된 최신 기능
- 무작위 시작 위치와 화재 위치
- 화재에서 실제 이동 거리가 가장 짧은 소화기를 지정하고 해당 소화기만 획득 가능
- 방 이름 및 글자 길이에 맞춘 이름표, 깜박이는 배치 미리보기
- 가로/세로 직선 벽 보정과 50x50px 지우개
- 계단 표시 50x50px, 소화기 및 화재 표시 2배
- 입장 시 중앙 '불이야!' 2초 표시
- 관리자 키 없이 설정 저장
- 전체보기 옆 맵 다시로드: 설정 JSON 선택 시 서버 맵 설정을 즉시 덮어쓰고 다시 읽기
- 제공된 소방관 사진 및 헬멧 중앙 119 마크 적용 (이미지 Index.html에 내장)
- 캐릭터, 소화기, 불 표시는 겹쳐도 불투명 유지
- 미션 시작과 이동 중 전체보기 유지
- 신규 3D 화면: 소방관 뒷모습, 달리기 동작, 우측 하단 정사각형 전체 미니맵
- 2.8m 벽과 천장 / 흰 텍스 천장 / 나무무늬 벽 / 갈색 줄눈 노란 타일
- 화재에서만 시간 경과에 따른 천장 회색 연기
- 관리자 지도와 동일한 데이터로 3D 생성, 방 출입구 지정 및 표지판

참고: https://developers.google.com/apps-script/concepts/deployments
