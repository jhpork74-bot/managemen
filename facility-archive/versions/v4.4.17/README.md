# v4.4.17 스프레드시트 연결설정

로컬·모의 Sheets/서버·Edge 검증 완료 / 실제 운영 적용 전.

[설치 및 사용](시트연결설정_설치안내.md)

연결설정 탭 C열 수정 → 미리보기 → 명시적 적용. 자동 onEdit 적용 없음. 독립형 프로젝트는 편집기 함수로, 바운드 프로젝트는 시트 메뉴로 실행합니다. 기존 데이터·설정·사진을 유지합니다. 초기 연결용 INI.gs는 유지하며 평소 ID는 시트에서 관리합니다. 인증키/웹훅은 ScriptProperties에만 둡니다. 공개 소스의 업무 시트 ID는 자리표시자입니다.
