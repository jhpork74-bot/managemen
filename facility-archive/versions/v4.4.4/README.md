# v4.4.4 소속별 세 달 당직표

상태: **로컬 검증 / 운영 확인 전**

소속 구분, 세 달, 이후 배치, 매월 20일·캘린더 알림 코드

이 번호는 2026-10-27에 붙인 보관용 번호입니다. 정확한 과거 배포 날짜나 배포 번호를 뜻하지 않습니다.

운영 데이터, API 인증키, 사진, 직원 명부 JSON은 포함하지 않습니다. 소스의 직원 실명 예시는 가명으로 바꾸고 스프레드시트 ID는 자리표시자로 바꿨습니다. 원래 소스는 사용자 PC에 그대로 유지했습니다.

복구할 때 이 폴더의 파일을 한 세트로 사용합니다. Index.html은 Apps Script의 Index HTML 파일에, .gs는 각각 같은 이름의 스크립트 파일에 넣습니다. Code.gs의 PASTE_YOUR_SPREADSHEET_ID_HERE를 본인 기존 스프레드시트 ID로 교체해야 합니다. 기존 코드에서 쓰던 ID를 먼저 보관하세요.

전체 JSON·Apps Script·시트 사본을 보관한 뒤 테스트 프로젝트에서 먼저 확인하세요. 과거 코드가 현재 데이터의 새 필드를 이해하지 못할 수 있으므로 실제 자료를 불러온 뒤 곧바로 저장하지 마세요. 코드 복원과 데이터 복원은 서로 다릅니다.

직원별 실명 예시를 가명으로 바꿨기 때문에 이름으로 제공하는 기본 추천·예시 순서는 실제 직원에 맞게 다시 설정해야 합니다. 기존 저장된 직원 ID 기반 배치는 이름 예시와 별개입니다.

운영 구글시트·공휴일 API·실제 휴대전화 알림 수신 검증을 통과했다고 주장하지 않습니다.
