# v4.4.27 기관명·폼텍 라벨 선택 설치

기관명 기본값은 **예시복지관**입니다. 제품이 아직 정해지지 않았으므로 처음에는 **제품 미정 / 직접 설정**으로 표시합니다. 이미 저장한 기관명이 있으면 그대로 유지하므로 필요한 경우 기관명을 고친 뒤 양식 설정 저장을 누르세요.

## v4.4.24·25·26 재물관리 설치자

1. 현재 웹앱에서 저장 완료를 확인하고 전체 JSON 백업을 내려받습니다. Apps Script의 기존 HTML 두 개도 별도로 복사해 보관하세요.
2. ZIP을 풀고 `1_재물관리_기설치자_교체2개` 폴더를 엽니다.
3. Apps Script 편집기 왼쪽의 **Index HTML**을 엽니다. 내려받은 `Index.html`의 내용 전체로 교체합니다.
4. **AssetManagementUI HTML**도 내려받은 `AssetManagementUI.html` 내용 전체로 교체합니다. 두 파일 모두 HTML입니다. Code.gs나 다른 스크립트에 붙이지 마세요.
5. 저장 후 **배포 → 배포 관리 → 기존 배포의 연필 → 버전: 새 버전 → 배포**를 누릅니다. 기존 웹앱 주소를 유지합니다.
6. 웹앱을 새로고침하고 재물관리등록에서 물품을 선택한 뒤 **라벨지출력**을 누릅니다.
7. 기관명을 확인하고 실제 사용하는 폼텍 제품번호를 고릅니다. 크기와 칸 수가 자동 입력됩니다. **인쇄 미리보기**로 확인하고 **양식 설정 저장**을 눌러 보관합니다.

설치 시 실행할 GS 함수는 없습니다. 기존 연결설정·사진 폴더·서명키를 변경하지 마세요. 재물관리가 없는 이전 버전은 포함된 `v4.4.24_기초설치안내.md`를 먼저 따르세요. 전체복구 폴더는 참고용이며 기존 사용자는 위 HTML 두 개만 교체합니다.

## 선택 가능한 제품

|폼텍 번호|한 칸 크기(mm)|A4 칸 수|
|---|---|---|
|3105|63.5 × 38.1|21|
|3106|64 × 34|24|
|3107|99.1 × 33.9|16|
|3108|99.1 × 38.1|14|
|3112|63.5 × 70|12|
|3114|99.1 × 67.7|8|
|3116|99.1 × 93.1|6|

크기와 칸 수는 [폼텍 공식 카탈로그](https://download.formtec.co.kr/item/pdf/Formtec_Catalog_Kor.pdf)를 참고했습니다. **간격·여백은 중앙 배치 초기값이며 제조사 칼선 위치를 검증한 템플릿은 아닙니다.** 실제 제품 포장 규격을 확인하세요. 목록에 없으면 직접 설정을 사용합니다. 너비·높이·칸 수를 직접 바꾸면 제품 선택은 직접 설정으로 바뀝니다.

## 출력 위치 맞추기

먼저 일반 A4 종이에 배율 100%, 머리글·바닥글 끔으로 시험 출력하고 실제 라벨지와 겹쳐 보세요. 가로·세로 간격과 여백을 조정하고, 전체 위치를 옮길 때는 가로/세로 위치 보정(mm)을 사용합니다. +가로는 오른쪽, +세로는 아래쪽입니다. 프린터 선택·출력을 누르면 브라우저 인쇄창에서 이미 연결된 네트워크 프린터를 선택할 수 있습니다. 프린터 설치나 무인 인쇄 기능은 아닙니다.

선택한 제품 규격을 되돌리려면 선택 규격 다시 적용을 누릅니다. 설정을 보관하려면 양식 설정 저장을 눌러야 합니다. 출력만으로 조사 완료나 물품 이동을 기록하지 않습니다. 기관명·연도·관리번호·물품명과 선택한 취득일·조사일·부서·장소·수량을 출력합니다.

## 검증과 보관
