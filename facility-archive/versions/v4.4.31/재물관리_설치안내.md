# v4.4.24 재물관리등록·업무일지 초안

기준 버전은 v4.4.23입니다. 재물관리 화면·계산·사진 조회를 AssetManagement.gs / AssetManagementUI.html로 분리했습니다. 기존 업무 시트·당직·CSFS·사진·저장 충돌 보호를 유지합니다. 이번 버전은 로컬 다운로드용입니다. 사용자가 등록을 요청하기 전에는 GitHub에 올리지 않습니다.

## 1. 먼저 보관하기

기존 웹앱에서 전체 JSON 백업을 다운로드하고, 저장되지 않은 변경은 클라우드 상태에서 미전송 임시본으로 따로 보관합니다. Apps Script 기존 소스와 ScriptProperties를 보관합니다. 특히 INI.gs의 `INI_LEGACY_SPREADSHEET_ID`와 사진 확인키 `REPAIR_PHOTO_SIGNING_KEY`를 유지해야 합니다. JSON 백업에는 Drive 사진 원본·권한·확인키가 포함되지 않습니다.

## 2. v4.4.23에서 교체할 파일

ZIP의 **1_교체파일** 폴더에서 다음 파일을 같은 이름의 기존 파일에 전체 교체합니다.

| 형식 | 파일 | 역할 |
|---|---|---|
| HTML | Index.html | 새 메뉴 포함·업무일지 하단 초안·재물 충돌 보호 |
| HTML | PopupBehaviorUI.html | 사진 입력 변경 및 저장 중 보호 |
| 스크립트 | Code.gs | 같은 업무 시트에 재물 보고용 탭 작성 |
| 스크립트 | FacilityStorage.gs | 버전 표시 갱신. v4.4.23 저장 보호 유지 |
| 스크립트 | INI.gs | 재물조사 사진 폴더 키 추가 |
| 스크립트 | ConnectionSettings.gs | 연결설정 시트에 재물조사 폴더 행 추가 |
| 스크립트 | RepairPhotoStorage.gs | 재물 사진 전용 폴더·서명 구분 |

**INI.gs를 교체하기 전에 현재 운영 파일의 `INI_LEGACY_SPREADSHEET_ID`를 기록하고, 새 파일에서도 같은 값으로 유지합니다.** 재물조사 폴더 ID를 이 값에 넣지 않습니다. 기존 ScriptProperties는 삭제하지 않습니다. INI.CS는 개발용 원본이며 Apps Script에 중복 설치하지 않습니다.

## 3. 새 파일 두 개 추가

ZIP의 **2_새파일** 폴더에서 추가합니다.

1. Apps Script 파일 옆 + → **스크립트** → `AssetManagement`를 만듭니다. `AssetManagement.gs` 전체 내용을 붙여 넣습니다.
2. 파일 옆 + → **HTML** → `AssetManagementUI`를 만듭니다. `AssetManagementUI.html` 전체 내용을 붙여 넣습니다.
3. 모두 저장합니다. 파일명은 정확하게 맞추고, HTML 내용을 .gs에 붙여 넣지 않습니다.

**3_전체복구용_참고**는 HTML 8개·GS 16개의 일관된 전체 세트입니다. 현재 23이 정상 설치되어 있으면 모두 교체할 필요 없이 위 9개 파일만 적용합니다. 구버전에서 전체 복구할 때도 기존 시트 ID와 비밀 설정을 유지합니다. 전체 파일에 임시 운영 자료는 들어 있지 않습니다.

## 4. 기존 연결설정 시트에서 재물조사 폴더 지정

사용자가 이미 만든 회사 Drive의 ‘재물조사’ 폴더를 사용합니다. 아직 폴더 ID를 받지 않았으므로 코드에 임의의 폴더를 넣거나 새 폴더를 생성하지 않았습니다.

1. 회사 Drive에서 재물조사 폴더를 엽니다. 주소가 `https://drive.google.com/drive/folders/폴더ID`라면 폴더ID 부분 또는 주소 전체를 복사합니다.
2. 이 폴더에 기존 웹앱 실행 계정의 편집 권한이 있는지 확인합니다. 회사 폴더를 사용한다고 관리자 이메일이나 원본 업무 시트를 바꿀 필요는 없습니다.
3. 기존 개인 관리자 Google 계정으로 Apps Script 편집기를 엽니다. 상단 함수 목록에서 **setupFacilityConnectionSettings**를 선택하고 실행합니다.
4. 기존 업무 스프레드시트의 **연결설정** 탭을 엽니다. 마지막에 **재물조사 사진 저장 폴더 / ASSET_IMAGE_FOLDER_ID** 행이 추가됩니다.
5. 그 행의 **노란 C열**에 재물조사 폴더 ID 또는 주소를 넣습니다. B열 키·D열 현재값·원본 시트 행은 수정하지 않습니다.
6. 편집기로 돌아와 **previewFacilityConnectionSettings**를 실행합니다. 변경 목록에 ASSET_IMAGE_FOLDER_ID가 있는지 확인합니다. 다른 행에 이전 입력이 남아 있으면 함께 적용될 수 있으므로 변경 목록 전체를 확인합니다.
7. **applyFacilityConnectionSettings**를 실행합니다. D열에 새 폴더 ID가 표시되면 설정 반영이 끝납니다. 셀에 입력만 해서는 적용되지 않습니다.

재물 폴더가 비어 있으면 사진 업로드를 중단하고 입력을 유지합니다. 개인 Drive나 다른 업무 사진 폴더로 자동 대체하지 않습니다. 기존 사진을 이동하거나 삭제하지 않습니다.

## 5. 배포하기

배포 → 배포 관리 → 현재 웹앱 선택 → 연필 수정 → 버전 ‘새 버전’ → 설명 ‘v4.4.24 재물관리등록’ → 배포합니다. 실행 계정과 접근 권한은 기존 설정을 유지합니다. 이전 웹앱 창은 닫고 기존 /exec 주소로 다시 엽니다. 하단에 v4.4.24가 보이는지 확인합니다.

## 6. 현장에서 사용하기

- **장소등록**: 본관 사무실·분관 프로그램실 등 장소를 먼저 등록합니다.
- **재물 신규등록**: 관리번호·물품명·수량·취득일·부서·최초장소·내용·사진을 입력합니다. 관리번호는 중복되지 않게 합니다. 취득일은 비워도 됩니다.
- **물품명 클릭**: 상세 내용과 사진, 전체 이동 이력을 확인합니다. 처음 여는 사진은 서버가 저장된 기록을 확인한 뒤 Drive에서 읽습니다. 같은 접속 중에 이미 불러온 사진은 재사용할 수 있습니다.
- **이동경로 추적**: 최초장소는 고정이며, 이동일과 마지막장소를 선택해 저장합니다. 두 번 이상 이동해도 중간 경로와 직전장소를 모두 보존합니다. 과거 이력은 삭제하지 않습니다. 묶음 수량 전체를 이동하므로 일부만 이동할 때는 구분 관리번호로 별도 등록합니다.
- **조사 결과 저장**: 조사일을 지정하고 실제 확인한 물품을 체크한 후 저장합니다. 조사 당시 장소·수량·상태의 기록이 남습니다. 조사 확인만으로 장소를 바꾸지는 않습니다.
- **차후 불용 저장 → 불용처리 완료**: 선택 물품의 상태를 바꾸며 이력을 보존합니다. 불용예정은 ‘불용예정 취소’로 사용중으로 돌릴 수 있습니다. 불용완료 물품은 이동할 수 없습니다.
- **라벨지 프린터**: 선택한 물품의 관리번호·물품명·부서·현재장소를 브라우저 인쇄로 보냅니다. 60mm 기본 라벨 배치이며 실제 라벨지 규격·프린터 드라이버·인쇄 여백은 인쇄창에서 맞춥니다. 특정 프린터에 자동 연결하는 기능은 아닙니다.
- **조회/초기화**: 물품명·관리번호·장소·부서·상태를 조회합니다. 초기화는 조회 조건만 지웁니다. 조회 조건을 바꾸면 이전 선택을 해제합니다.

태블릿에서는 16~17px 기본 글자와 48px 이상 터치 버튼을 사용합니다. 팝업은 화면 크기에 맞춰 줄어들고 내용이 길면 내부 스크롤됩니다. 태블릿·휴대전화의 좁은 화면에서는 물품별 카드로 전환되어 내용과 관리 버튼을 읽기 쉽게 보여줍니다. 인터넷 연결이 필요하며 사진 업로드는 오프라인에서 완료되지 않습니다.

## 7. 데이터 시트와 사진

원본은 기존 공통 JSON의 `assetManagement`에 함께 저장합니다. 보고용으로 같은 스프레드시트에 **재물관리대장 / 재물이동이력 / 재물조사기록** 탭이 추가됩니다. 원본 저장 후 보고용 탭은 별도 갱신되므로 잠시 늦게 표시될 수 있습니다. 필요하면 클라우드 상태의 ‘보고용 시트 재생성’을 누릅니다. 보고용 탭을 직접 편집해 앱 자료를 바꾸는 방식은 지원하지 않습니다.

사진은 ASSET_IMAGE_FOLDER_ID 폴더의 비공개 JPG로 저장하며 업무 JSON에는 연결 참조만 보관합니다. 저장된 물품의 사진인지 확인한 뒤 조회합니다. 사진 연결 해제·수정도 Drive 원본 삭제와 별개입니다. 사진 확인키는 기존 고장·공사·CSFS와 공통이므로 삭제하거나 새로 만들지 않습니다.

## 8. 업무일지 하단 초안 변경

위쪽 15일 캘린더는 모든 업무·점검을 기존 기준대로 보여줍니다. **하단 업무일지 초안만** 조회일 앞뒤 7일의 일일 일반 등록 업무를 대상으로 합니다. 반복업무·주간/월간업무·점검 예약은 제외합니다. 완료는 ‘완료’, 예정·진행 중은 ‘미완료’로 표시하며 진행 중은 부가 표기합니다. 위쪽 상태 필터가 완료여도 하단에는 완료/미완료를 함께 담습니다.

저장한 예전 초안은 자동으로 덮어쓰지 않습니다. 설치 후 **‘일일 일반업무로 초안 새로 만들기’ → 내용 확인 → 초안 저장**을 눌러 새 기준을 적용합니다. 초안 편집은 실제 업무 상태를 바꾸지 않습니다.

## 9. 진단과 복구

4_선택진단의 AssetCheck.gs는 선택적 진단 파일입니다. 스크립트 AssetCheck로 추가한 뒤 **checkAssetDriveConnection**을 실행하면 설정·모듈·폴더 조회 여부를 출력합니다. 진단은 폴더 쓰기나 실제 사진 저장을 하지 않습니다. Check 파일 첫 줄에는 요청한 테스트용 주석을 넣었습니다.

운영 적용 전 로컬 모델·모의 Drive/Sheets·브라우저 검증을 수행했습니다. 실제 회사 재물조사 폴더 ID·쓰기는 사용자가 설정한 뒤 확인해야 합니다. 운영 배포·실물 태블릿 카메라·특정 라벨 프린터는 아직 검증하지 않았습니다.

되돌릴 때는 보관한 v4.4.23 전체 소스와 배포를 복원하고 기존 설정과 사진을 유지합니다. 이미 입력한 재물 자료는 JSON의 알 수 없는 필드로 남으므로 임의로 삭제하지 않습니다. 기존 보고용 탭도 삭제하지 않습니다.
