# v4.4.31 재물관리 화면 실행 오류 수정

## 확인된 내용

사용자가 제공한 실제 운영 웹앱을 읽기 전용으로 확인했습니다. 하단은 v4.4.30이었고 재물관리 버튼은 있으나 화면 파일이 실행되지 않았다는 안내가 나왔습니다. 브라우저에는 `SyntaxError: missing ) after argument list`가 기록되어 있었습니다.

운영 브라우저가 받은 재물관리 스크립트와 원본을 비교하니 갤러리 파일 선택창의 image 와일드카드 문자열 중간에서 코드가 끊기고 장소등록·이동·담당자 팝업을 만드는 부분도 누락되어 있었습니다. 관리자 계정 비교와는 별개의 화면 스크립트 문제입니다. 운영 데이터의 등록·수정·저장·삭제는 수행하지 않았습니다.

사진 입력 HTML 문자열 안의 와일드카드를 제거하고 DOM 생성 후 동일한 이미지 필터를 설정하게 수정했습니다. 화면 include도 `HtmlService.createTemplateFromFile('AssetManagementUI').getRawContent()`로 바꾸어 고정 파일의 원문을 가져옵니다. getRawContent는 [Google 공식 문서](https://developers.google.com/apps-script/reference/html/html-template#getRawContent())에 설명된 원문 조회 메서드입니다. Google 내부 변환 과정 자체를 직접 검사한 것은 아니며, 위 누락 위치와 주석 제거 모의 재현을 근거로 이 경로를 보완했습니다.

## 설치 — 이미 v4.4.30 전체통합 적용 시

ZIP의 **1_실행수정_교체3개**를 사용합니다.

1. Apps Script **Index HTML**을 내려받은 Index.html 전체 내용으로 교체합니다.
2. **AssetManagementUI HTML**을 AssetManagementUI.html 전체 내용으로 교체합니다.
3. **AssetManagement 스크립트**를 AssetManagement.gs 전체 내용으로 교체합니다. 이 파일은 GS입니다. HTML을 넣지 마세요.
4. 모두 저장합니다. 별도 함수를 실행하거나 관리자/Drive/시트 설정을 바꿀 필요가 없습니다.
5. **배포 → 배포 관리 → 현재 배포의 연필 → 버전 새 버전 → 배포**합니다. 실행 계정과 접근 범위는 그대로 둡니다.
6. 기존 웹앱을 닫고 같은 배포의 /exec 주소로 다시 접속합니다. 하단 **v4.4.31 · 재물화면 실행수정**을 확인합니다.
7. 재물관리등록 메뉴를 눌러 신규등록/장소등록/담당자 일괄지정/라벨지출력 버튼과 물품 목록을 확인합니다. 실제 업무 저장은 화면이 열린 뒤 사용자가 확인하며 진행하세요.

## 전체 세트가 필요한 경우

**2_전체소스_설치용**은 HTML8개/GS16개 전체입니다. 파일별 HTML/스크립트 구분은 동봉한 v4.4.30 전체통합 안내를 참고합니다. 기존 INI_LEGACY_SPREADSHEET_ID와 ScriptProperties, 사진 서명키를 유지하세요. 운영 시트·사진·권한·트리거는 초기화하지 않습니다. 기존 데이터와 담당자/폼텍/사진/이동 기능은 그대로 유지합니다.

## 검증 범위

손상된 운영 스크립트가 실제 구문 오류를 내는 것을 로컬에서 확인했습니다. 수정 소스는 전체 팝업 포함, 이미지 필터 유지, 일반 구문 및 블록 주석 제거 모의 처리 후 구문, 원문 include 모의 검사를 통과했습니다. 기존 재물·사진·담당자·라벨 보호 검사도 통과했습니다. 실제 Google 프로젝트에 수정본을 배포한 것은 아니므로 운영 성공 여부는 위 설치 후 확인해야 합니다. 실물 라벨 인쇄는 미검증입니다. GitHub에는 게시하지 않았습니다.
