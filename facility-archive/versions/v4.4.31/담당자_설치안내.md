# v4.4.28 담당자 등록·일괄지정·라벨 표시

## 사용 방법

1. 재물관리등록 메뉴에서 물품 체크박스를 선택합니다. 현재 조회 물품 전체 선택도 사용할 수 있습니다. 검색 조건을 바꾸면 기존 선택은 해제됩니다.
2. 상단 **담당자 일괄지정**을 누릅니다.
3. 선택한 물품 목록을 확인하고 담당자 이름을 입력합니다. **선택 물품에 저장**을 누르면 선택한 물품의 기존 담당자를 새 이름으로 변경합니다. 빈 이름은 일괄 저장하지 않습니다.
4. 저장 완료가 표시되면 선택은 유지됩니다. **라벨지출력 → 폼텍 제품 선택 → 인쇄 미리보기**를 누르면 지정한 담당자가 라벨에 표시됩니다. 라벨의 담당자 표시 항목은 기본으로 체크됩니다.
5. 물품 한 개의 담당자는 제품사진 아래 **변경**에서 수정할 수 있습니다. **등록**은 사진 전용으로 물품 정보는 읽기 전용입니다. 물품명을 누르면 상세 정보에서 담당자를 확인할 수 있습니다.

기존 물품에는 담당자를 임의로 채우지 않습니다. 지정 전 라벨은 담당자 **미입력**으로 표시합니다. 개별 변경에서 담당자 칸을 비우면 담당자를 지울 수 있습니다. 사진·수량·장소·이동 이력·조사 기록은 일괄지정으로 변경하지 않습니다. 담당자를 저장해도 조사 완료로 처리하지 않습니다.

## 설치 — 재물관리 v4.4.24~27 설치자

1. 저장 완료를 확인한 뒤 전체 JSON 백업과 기존 소스 사본을 보관합니다.
2. ZIP의 **1_재물관리_기설치자_교체3개** 폴더를 엽니다.
3. Apps Script의 **Index HTML**을 내려받은 `Index.html` 내용 전체로 교체합니다.
4. **AssetManagementUI HTML**을 `AssetManagementUI.html` 내용 전체로 교체합니다.
5. **AssetManagement 스크립트**를 `AssetManagement.gs` 내용 전체로 교체합니다. HTML은 `.gs` 파일에 넣지 마세요. 이번 버전은 HTML 두 개와 GS 한 개, 총 세 개를 함께 교체합니다.
6. 저장 → 배포 → 배포 관리 → 기존 배포의 연필 → 버전: 새 버전 → 배포를 누릅니다. 기존 웹앱 주소를 유지합니다.
7. 웹앱을 새로고침하고 물품 체크 → 담당자 일괄지정 → 저장 → 라벨 미리보기 순으로 확인합니다.

별도 설치 함수 실행은 필요 없습니다. 기존 시트 ID·회사 Drive 폴더·관리자·서명키를 바꾸지 마세요. 재물관리가 없는 버전은 포함된 v4.4.24 기초설치안내를 먼저 따릅니다. 전체복구 소스는 참고용이며 기존 사용자는 위 세 개만 교체합니다. 선택진단 Check 파일은 필수가 아닙니다.

## 데이터·출력·검증

기존 canonical JSON에 물품별 manager 필드를 추가합니다. 공통 저장 ACK·충돌 보호를 유지합니다. 일괄 창을 연 뒤 선택 물품이 변경되면 중단하고 최신 목록을 다시 선택하도록 안내합니다. 저장 중 중복 클릭은 차단하며 실패 시 입력·선택을 유지하고 완료로 표시하지 않습니다. 재물관리대장 보고 탭은 기존 열 뒤에 담당자 열을 추가합니다. 보고 탭은 지연 생성되므로 원본 저장 완료와 갱신 시각이 다를 수 있습니다.

여러 물품 일괄지정·선택 외 자료 보존·기존 사진과 이력 보존·잘못된 입력 거부·개별 담당자·라벨 이스케이프·담당자 변경 시 오래된 라벨 출력 차단·보고 열 및 기존 재물/사진/저장·출력 가드 모의 검증을 통과했습니다. 로컬 모의 웹앱에서 전체 선택·지정·저장 완료·선택 유지·3108 라벨 담당자 표시와 글자 잘림 없음을 확인했습니다. 실제 Google 운영 배포와 실물 인쇄는 확인하지 않았습니다. 폼텍 간격/여백은 초기값이므로 일반 종이 시험 출력으로 맞추세요.
