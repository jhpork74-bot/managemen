# v4.4.31 재물관리·담당자·라벨 및 화면 실행 수정

사용자 명시 요청에 따른 공개 비식별화 소스 보관입니다. 상태: 사용자 선택 보관 / 로컬·모의 검증. 운영 무오류 또는 실물 라벨 출력 성공을 독립 확인했다는 뜻은 아닙니다.

[설치 안내](실행수정_설치안내.md) · [전체통합 설치](전체통합_설치안내.md) · [담당자](담당자_설치안내.md)

전체 HTML8개·GS16개와 선택 Check3개, 재물 개발 원본·빌더·검증 코드를 포함합니다. 재물 등록/회사 Drive 사진/이동 이력/연간 조사/담당자 개별 및 일괄지정/폼텍 선택/라벨 및 일일 일반업무 초안 기능을 포함합니다. v30의 운영 브라우저 소스 손상을 읽기 전용으로 확인하고 사진 필터 문자열과 고정 UI 원문 include를 수정했습니다. 수정본의 Google 배포와 실물 인쇄는 미검증입니다.

공개 사본의 기관명과 운영 ID는 예시·자리표시자입니다. 설치 시 기존 운영 INI_LEGACY_SPREADSHEET_ID·Drive 설정·ScriptProperties·서명키를 별도로 복원해야 합니다. 운영 JSON·사진·직원 실명·실제 브라우저에서 추출한 진단 원문은 포함하지 않습니다. 코드 보관으로 데이터·권한·트리거까지 복구되지 않습니다. v24~30 중간 로컬 폴더는 이번 등록 범위가 아닙니다.
