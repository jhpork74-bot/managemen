# v4.4.26 라벨지출력·재물조사표 스티커

버튼 이름을 **라벨지출력**으로 바꾸고 기관용 재물조사표 스티커 양식을 추가했습니다. 기관명/연도/관리번호/물품명을 기본으로, 취득일·조사일·부서·현재장소·수량을 선택해 표시합니다. 정부 인장·공식 인증을 표시하거나 전자태그(RFID)를 발급하는 기능은 아닙니다. 기관의 실제 양식과 라벨지 규격에 맞춰 사용합니다.

## v4.4.24 또는 v4.4.25가 설치되어 있다면

1. 기존 소스와 업무 JSON을 보관합니다.
2. ZIP의 **1_재물관리_기설치자_교체2개** 폴더를 엽니다.
3. Apps Script의 **HTML 파일 AssetManagementUI** 전체 내용을 AssetManagementUI.html로 교체합니다.
4. **HTML 파일 Index** 전체 내용도 Index.html로 교체합니다. 두 파일 모두 HTML이며 .gs에 넣지 않습니다.
5. 저장 → 배포 → 배포 관리 → 현재 웹앱 연필 수정 → 버전 ‘새 버전’ → 배포합니다.
6. 이전 웹앱 창을 닫고 기존 /exec 주소로 다시 접속합니다. 하단 v4.4.26과 라벨지출력 버튼을 확인합니다.

기존 원본 시트·회사 Drive 사진 폴더·관리자 계정·사진 키 설정을 유지합니다. 스크립트 교체나 연결설정 재적용은 필요하지 않습니다. 사진 카드의 등록/변경, 이동 이력, 업무일지 하단 반복 제외 기준과 저장 충돌 복구도 유지합니다.

아직 재물관리 기능이 없는 구버전이라면 두 HTML만 적용하지 않습니다. 함께 넣은 **v4.4.24_기초설치안내.md**의 설치 순서를 따르고 이번 ZIP의 **2_전체복구용_참고** 소스를 사용합니다. 전체 세트는 HTML 8개·GS 16개이며 기존 INI 승계 시트 ID·ScriptProperties를 보존해야 합니다. Check3개는 별도 선택 진단입니다.

## 사용 순서

1. 재물관리등록에서 라벨을 붙일 물품을 체크합니다.
2. **라벨지출력**을 누릅니다.
3. 기관명을 입력하고 재물조사 연도와 표시 항목을 확인합니다.
4. A4 라벨지 또는 한 장씩 출력하는 라벨 프린터 용지를 선택합니다.
5. 라벨 너비·높이(mm), 칸 수, 간격·여백을 실제 라벨지 규격에 맞춥니다.
6. **인쇄 미리보기**를 눌러 글자가 칸을 벗어나지 않는지 확인합니다. 내용을 넘기면 출력 대신 크기·글자 조정 안내가 나옵니다.
7. 자주 쓸 기관명·규격은 **양식 설정 저장**으로 기존 업무 데이터에 보관합니다. 물품 내용과 이동·조사 이력을 바꾸지는 않습니다. 다음에 열 때 첫 출력 칸과 매수는 1로 돌아갑니다.
8. **프린터 선택·출력**을 누릅니다. 기기의 인쇄창에서 설정된 네트워크 프린터를 선택합니다.
9. 용지 크기를 맞추고, 배율 100%, 머리글·바닥글 끔으로 설정합니다. 먼저 일반 종이에 한 장 출력해 실제 스티커와 위치를 대조한 뒤 라벨지로 출력합니다.

기본 A4 규격은 **90×40mm / 2열×6행 / 가로 간격3mm·세로 간격4mm / 좌우·상하 여백10mm**입니다. 특정 제조사 제품 규격으로 보증한 값이 아닙니다. 한 장씩 출력 모드는 기본70×45mm이며 프린터가 지원하는 실제 라벨 크기로 바꿉니다. 단면/양면, 급지함, 라벨지 종류는 프린터 드라이버에서 설정하며 보통 단면을 사용합니다.

첫 출력 칸은 첫 페이지 왼쪽 위부터 가로 순서입니다. 12칸 중 앞의 5칸을 썼다면 6을 입력합니다. 다음 페이지는 1번 칸부터 이어집니다. 한 번에 500장 이하를 만들 수 있으며 물품별 매수는 1~20장입니다. 수량이 여러 개인 물품도 기본은 한 장이므로 필요 매수를 별도로 입력합니다.

## 네트워크·인터넷 프린터 설정

웹앱이 프린터를 설치하거나 IP 주소로 직접 인쇄 작업을 보내는 방식은 아닙니다. PC/태블릿에 연결·설치된 프린터를 시스템 인쇄창에서 선택합니다. 웹앱에서 자동으로 프린터를 검색하거나 기본 프린터를 바꾸지 않습니다.

- **Windows PC**: 설정 → Bluetooth 및 장치 → 프린터 및 스캐너 → 장치 추가에서 회사 네트워크 프린터를 등록합니다. 자동 검색되지 않으면 기관에서 제공한 프린터 이름·주소로 수동 추가합니다. 기관의 드라이버와 권한이 필요할 수 있습니다.
- **태블릿**: 기기의 인쇄 서비스가 해당 프린터를 지원해야 합니다. 네트워크 연결과 제조사 인쇄 서비스/AirPrint 지원 등은 기기와 프린터에 따라 다릅니다. 목록에 나오지 않으면 같은 웹앱을 프린터가 설치된 PC에서 열어 출력할 수 있습니다.
- **인쇄창**: 네트워크 프린터 대신 PDF로 저장을 선택하면 파일로 보관할 수 있습니다. 출력 버튼을 눌렀다는 이유만으로 앱이 실제 출력 완료나 조사 완료를 기록하지 않습니다. 취소할 수도 있습니다.

기본 출력은 **재물조사표**입니다. 실제 조사일은 기존에 조사 결과 저장으로 기록한 날짜를 쓰며, 기록이 없는 물품은 **미조사**라고 표시합니다. 출력으로 조사 결과나 마지막장소가 바뀌지 않습니다. 출력 직전에 서버 자료를 다시 조회하고, 선택한 내용이 바뀌었거나 아직 저장 중이면 출력 대신 다시 확인하도록 합니다. 이 확인에는 인터넷 연결이 필요합니다.

## 검증·보관

라벨 배치·첫 칸·매수·페이지 분리·규격 초과·문자 이스케이프·설정 저장값과 기존 재물/사진/업무일지 모의 검증을 통과했습니다. 로컬 브라우저에서 실제90×40mm 치수, 글자 넘침 없음, 양식 설정 저장과 미리보기를 확인했습니다. 실제 네트워크 프린터·용지 급지·부착 위치·태블릿 인쇄 서비스는 기관 환경에서 한 장 시험해야 합니다. 운영 배포와 실제 프린터 출력은 수행하지 않았습니다.
