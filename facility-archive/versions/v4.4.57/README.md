# v4.4.57 시설관리 통합업무

HTML 13개와 GS 22개. 이관 후 조회일 유지, AUTO, 민원 보기, 저장 개선, 음성 및 키패드를 포함합니다. 운영 배포와 실기기 동작은 확인 전입니다.

월간 캘린더에서 이관한 업무는 다음 근무일로 이동합니다. 보고 있던 날짜와 월이 유지되어 다른 업무를 이어서 이관할 수 있습니다.

기존 v4.4.56 설치는 Index HTML을 교체한 뒤 웹앱 배포를 새 버전으로 갱신합니다. 전체 복원 시 같은 이름의 HTML과 스크립트를 Apps Script에 설치하고 운영 연결 설정을 승계합니다. AUTO 자동 점검은 설치할 계정의 편집기에서 AUTO를 실행해 등록합니다.

공개 사본은 예시 이름과 자리표시자를 사용합니다. 운영 데이터, 설정값, 자격 증명, 트리거 및 권한은 별도로 관리합니다.
