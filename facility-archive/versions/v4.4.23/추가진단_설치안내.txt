시설관리 v4.4.23 추가 진단 파일

두 파일은 웹앱 필수 실행 파일이 아니라 연결·계정을 확인하는 진단용 스크립트입니다.
기존 프로젝트에 설치했다면 유지할 수 있습니다. 이 파일이 없다는 이유만으로 웹앱 저장이 실패하지는 않습니다.

1. 압축을 해제합니다.
2. Apps Script 편집기 왼쪽에서 CSFSCheck.gs를 엽니다.
   없다면 파일 옆 + → 스크립트 → 이름 CSFSCheck로 새로 만듭니다.
3. CSFSCheck.gs 전체 내용을 붙여 넣습니다. 기존 파일이 있으면 내용을 전체 교체합니다.
4. 같은 방법으로 스크립트 AccountCheck를 만들거나 기존 AccountCheck.gs 전체 내용을 교체합니다.
5. 저장합니다. 두 파일 모두 HTML이 아닌 스크립트(.gs)입니다.

CSFS 확인: 함수 목록에서 checkCSFSDriveConnection 선택 → 실행.
계정 확인: 함수 목록에서 checkAccount 선택 → 실행.

AccountCheck는 최신 INI.gs에 있는 checkFacilityAdminAccounts 함수를 호출합니다.
INI.gs에 같은 함수를 다시 복사하지 않습니다. 개인·회사 계정 복수 등록을 지원하며 이메일 원문은 로그에 출력하지 않습니다.
checkAccount는 과거 단일 문자열 비교 대신 최신 진단으로 연결한 호환 파일입니다.

CSFSCheck는 기존 제공 진단과 같은 내용이며 기존에 지정한 회사 폴더 연결과 모듈 상태를 확인합니다.
이 진단은 폴더 조회만 확인합니다. 파일 쓰기·새 웹앱 배포·실제 사진 업로드 성공을 보장하지 않습니다.
회사 폴더를 이후 변경했다면 CSFSCheck의 expected 값도 확인하려는 새 폴더 ID로 맞춥니다.

두 파일은 설정·사진·업무 자료를 변경하지 않으며 잔디·메일을 보내지 않습니다.
운영 기능의 설치는 기존 v4.4.23 설치안내에 따라 계속 진행하세요.
