# v4.4.23 저장 충돌 복구 개선

사용자가 이 버전의 GitHub 등록을 명시적으로 요청했습니다. 상태: **사용자 선택 보관 / 로컬·모의 검증 완료**. 실제 운영 무오류 여부를 독립적으로 검증했다고 표시하지 않습니다.

[설치안내](설치안내.md) · [변경내용과 판단 근거](변경내용.md)

v4.4.22의 CSFS·회사 사진·당직·잔디 기능을 유지한 전체 소스입니다. v4.4.22 설치자는 Index HTML과 FacilityStorage.gs 두 파일을 함께 교체합니다. 기준 임시본 보존, 다른 업무 영역·독립된 완료 체크 합치기, 같은 영역 비교·선택, 최근 요청 결과 확인, 읽기 전용 최신 버전 조회를 추가했습니다. CSFSCheck.gs와 AccountCheck.gs는 선택적 읽기 전용 진단 파일입니다.

새 복구 모의 시나리오 18개 및 기존 저장·CSFS·사진·당직 변경·복구 검증을 통과했습니다. 로컬 브라우저의 충돌 선택 흐름도 확인했습니다. 이전 버전에서 상속한 브라우저 테스트 전체를 이 게시 작업에서 다시 실행한 것은 아닙니다. 새 환경의 실제 Google 저장·사진·잔디 수신은 별도 확인이 필요합니다.

공개 사본에는 실제 원본 시트·회사 폴더 ID, 직원 이름, 비밀 설정, 운영 JSON과 사진이 없습니다. 설치 시 기존 운영 설정을 복원해야 합니다. 진단 스크립트의 CSFS_FOLDER_PLACEHOLDER도 실제 폴더 ID로 맞춰야 합니다. 코드 보관은 운영 배포·데이터·사진·권한·트리거 복원을 대신하지 않습니다.
