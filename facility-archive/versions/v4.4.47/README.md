# v4.4.47 시설관리 통합업무

사용자 명시 요청에 따른 공개 소스 보관입니다. 전체 HTML11개·GS19개, 선택 진단3개와 최근 변경 원본을 포함합니다.

Figma 기반 화면, 태블릿 메뉴, 재고 카드, 소화기현황, 배움터 및 책갈피, 음성입력·지우기 버튼, 월간점검 전용 완료율, 캘린더 요약 정리와 업무등록 상단 취소/저장 버튼을 포함합니다. 음성은 PC 브라우저/Android 전용 음성키보드를 사용하며 Android APK 4.4.40-1 설치와 권한·키보드 선택이 필요합니다. 이 보관에는 APK/서명키를 포함하지 않습니다.

## 설치

HTML은 같은 이름 HTML에, GS는 같은 이름 스크립트에 추가하거나 교체합니다. Index는 템플릿 평가가 필요합니다. FacilityTheme.gs 및 FacilityThemeUI.html을 함께 설치하세요. 운영 INI의 시트 ID를 공개 사본의 자리표시자로 덮어쓰지 말고 기존 운영 값을 승계하세요. ScriptProperties·사진 서명키·Drive 권한·트리거·업무 JSON은 별도 보존합니다. 저장 후 현재 웹앱 배포를 새 버전으로 갱신합니다.

v4.4.46에서의 변경은 Index HTML의 업무등록/수정창 상단 버튼 배치입니다. 기존 데이터와 공통 저장 흐름을 유지합니다. 월간점검 완료율은 해당 월 완료 수/월간점검 전체 항목 수입니다.

## 검증 범위

현재 전체 GS 및 HTML 스크립트 구문 통과. 이전 변경에서 저장 복구 모의20개, 재고/소화기, 월간 완료율8개, 클릭4개 및 지우기 로컬 브라우저 검사를 수행했습니다. 최신 상단 버튼은 ID 단일성/submit 유지·구문 검사이며 실기기 배치는 미검증입니다. 사용자 선택 보관이며 운영 전체 무오류 확인을 뜻하지 않습니다. 실제 Google 배포·다중기기 저장·기기 음성인식은 배포 후 확인합니다.
