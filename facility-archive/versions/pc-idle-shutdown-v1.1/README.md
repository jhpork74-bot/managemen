# PC 미사용 자동종료 v1.1

Windows에서 마우스·키보드 미사용 시간이 1시간이 되면 PC 종료를 요청하는 별도 프로그램입니다. 시설관리 웹앱과 독립적으로 실행됩니다.

- 59분 미사용 뒤 60초 안내. 추가 입력이나 취소 시 다시 계산합니다.
- 일시정지/다시 시작, 트레이 아이콘, 절전 복귀·잠금 해제 시 초기화.
- 종료 버튼/메뉴는 기본 숨김. **Ctrl+F1**으로 표시/숨김 전환. 창을 숨기면 다시 숨겨집니다.
- Ctrl+F1은 화면 표시 제어이며 비밀번호 인증 기능은 아닙니다.
- 종료 명령은 shutdown /s /t 0이며 강제 종료 옵션이 없습니다. 미저장 문서가 종료를 막을 수 있습니다.
- 영상 시청·다운로드도 입력이 없으면 미사용으로 계산합니다. 필요할 때 일시정지하세요.

## 실행·설치

1. 같은 폴더의 실행파일 PC미사용자동종료.exe를 실행하거나 PC자동종료_v1.1.zip을 압축 해제합니다.
2. Windows 로그인 때 자동 실행하려면 시작프로그램등록.vbs를 실행합니다. 파일을 받은 것만으로 자동 등록하지 않습니다.
3. 등록 뒤 폴더 위치를 유지하세요. 이동했으면 다시 등록합니다.
4. 해제는 시작프로그램등록해제.vbs로 합니다. 현재 실행을 끝내려면 Ctrl+F1을 누른 뒤 종료합니다.
5. X는 트레이로 숨깁니다. 다른 프로그램이 Ctrl+F1을 점유하면 상태창을 선택한 뒤 누릅니다.

.NET Framework 4.x Windows 데스크톱 앱입니다. 인터넷·Google 계정·업무 데이터가 필요하지 않으며 입력 내용은 기록하지 않습니다.

## 소스·검증·보관

- build.ps1: 실행파일과 시간정책 테스트 빌드. 현재 프로그램을 실행하거나 시작프로그램을 등록하지 않습니다.
- IdleShutdown.cs / IdlePolicy.cs / PolicyTests.cs: 전체 C# 소스.
- 9개 시간정책 검사 통과. 개발 중 실제 PC 종료는 실행하지 않았습니다.
- 2026-11-05 사용자가 프로그램 동작에 만족한다고 확인하고 이 버전의 GitHub 보관을 명시적으로 요청했습니다. 특정 기기/시간별 시험 전체를 별도로 증명한 것은 아닙니다.
- 기존 웹앱 보관본과 운영 배포는 변경하지 않습니다. 로컬 설치 경로·설치 결과·업무 자료는 제외했습니다.
