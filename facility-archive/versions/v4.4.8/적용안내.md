# v4.4.8 달력 직원 이름만 표시

본관·분관 당직 달력에서 당직: 접두어를 빼고 직원 이름만 표시합니다. 점심대체 표시와 저장 자료·순번은 그대로입니다.

v4.4.7 전용 파일 분리 구성을 설치한 상태에서 적용합니다.

1. 현재 DutyManagementUI.html 내용을 먼저 보관합니다.
2. 내려받은 DutyManagementUI.html을 메모장으로 열어 전체 복사합니다.
3. Apps Script 왼쪽의 **DutyManagementUI HTML 파일**을 선택하고 내용 전체를 교체합니다. **스크립트 .gs 파일에 붙이지 않습니다.**
4. Ctrl+S → 배포 → 배포 관리 → 기존 배포의 연필 → 새 버전 → 배포합니다.
5. 기존 웹앱 주소를 새로고침합니다.

이번 변경은 HTML 한 파일만 교체합니다. Code.gs, Index.html과 다른 .gs 파일은 교체하지 않습니다. 아직 v4.4.7의 전용 파일 분리를 설치하지 않았다면 해당 버전의 분리 설치부터 완료해야 합니다.

운영 웹앱 배포와 실제 데이터 수정은 수행하지 않았습니다.
