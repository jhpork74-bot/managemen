# v4.4.6 미배정 고정 대체자·달력 두 번째 줄 정리

이번 번호는 GitHub 보관용 번호입니다. 운영 웹앱은 아직 자동 변경하지 않았습니다.

## 달라진 점

1. ‘인원 추가·수정 → ② 당직자·점심대체자 고정배치’의 점심당직 목록에 **본관·분관 소속이 아직 없는 직원**도 표시합니다. 이름 뒤에 `(미배정)`을 붙입니다.
2. 미배정 직원을 고정 대체자로 골라도 소속을 본관이나 분관으로 바꾸지 않습니다. 현재 장소 직원과 미배정 직원만 보이며, 다른 장소에 소속된 직원과 사용 중지 직원은 제외합니다.
3. 직원 등록창과 직원별 고정 대체 설정에도 같은 선택 범위를 적용했습니다.
4. 일반당직과 자동 점심대체 순번은 기존처럼 장소별 직원만 사용합니다. 미배정 직원을 일반당직이나 자동 순서에 자동 추가하지 않습니다.
5. 월 당직 달력에서 **점심대체가 필요한 날에만 두 번째 줄**을 표시합니다. 대체가 필요 없는 날은 ‘점심: 미지정’ 줄 자체를 만들지 않습니다.

‘미배정’은 점심대체자를 비워 두는 선택지가 아니라 **소속이 없는 실제 등록 직원**입니다. 고정배치 저장에는 실제 대체자를 선택해야 합니다. 자동/고정 대체 규칙과 기존 달력 데이터는 유지합니다.

## 교체 순서

1. 현재 Apps Script 소스와 전체 데이터 JSON을 먼저 백업합니다.
2. 내려받은 **Index.html**을 메모장으로 열고 전체 복사합니다.
3. Apps Script 왼쪽의 **Index (HTML 파일)**를 선택해 편집창 내용을 전체 교체합니다.
4. **DutyManagement.gs**도 이번 파일 전체 내용으로 교체합니다.
5. Ctrl+S → 배포 → 배포 관리 → 기존 웹앱의 연필 → 새 버전 → 배포합니다.
6. 기존 웹앱을 새로고침하고 고정배치 목록에서 `(미배정)` 표시를 확인합니다.

**Code.gs는 교체하지 않습니다. Index.html을 Code.gs에 붙여 넣으면 Unexpected token '<' 오류가 납니다.** 이번 ZIP에는 교체할 두 파일과 이 안내서만 들어 있습니다. 전체 통합 Index이므로 당직 추가코드를 다시 붙이지 않습니다.

소속이 없는 직원은 사용 중인 직원으로 등록되어 있어야 합니다. 다른 장소로 소속을 지정한 직원은 미배정 목록에 나타나지 않습니다.

## 검증

미배정 직원의 양쪽 장소 고정 선택, 저장·다음 달 반복, 소속 유지, 비활성/다른 장소/동일인 차단, 일반·자동 순번 유지, 대체 필요 여부에 따른 달력 두 번째 줄 유무를 시험했습니다. 기존 순번·월 연결·20일 자동작성·중복 알림 방지의 모의 시험도 실행합니다. 브라우저는 로컬 Edge와 모의 Google 응답을 사용하며 360/390px 화면을 확인합니다.

실제 운영 구글시트·공휴일 API·모바일 알림 수신·운영 웹앱 배포는 이 작업에서 실행하지 않습니다. GitHub 보관본은 직원 실명과 운영 식별 정보를 제거한 사본이며, 이 설치 ZIP은 현재 PC의 기존 연결 설정을 유지하는 교체본입니다.
