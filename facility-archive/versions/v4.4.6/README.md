# v4.4.6 미배정 고정 대체자·달력 두 번째 줄 정리

상태: **로컬 검증 통과 / 운영 사용 확인 전**

- 고정 점심대체자 목록에 현재 장소 직원과 소속 미지정 직원을 함께 표시합니다.
- 미지정 직원을 선택해도 직원의 소속은 바꾸지 않습니다.
- 다른 장소의 직원·미사용 직원·동일인·빈 선택은 고정 대체자로 저장하지 않습니다.
- 일반 당직과 자동 대체 순번의 장소별 범위는 유지합니다.
- 대체가 필요한 날에만 월 당직 달력 두 번째 줄을 표시합니다. 대체가 필요 없는 날의 미지정 줄은 제거했습니다.

[교체 방법과 검증 범위](교체및변경안내.md)

Index.html은 Apps Script의 HTML 파일 Index에 넣습니다. .gs 파일은 각각 같은 이름의 스크립트 파일입니다. GitHub 사본의 Code.gs에는 운영 ID가 없으므로 전체 복구 시 기존 본인 ID를 설정해야 합니다. 현재 운영 프로젝트에서 두 파일만 교체할 때는 기존 Code.gs를 유지합니다.

원본 설치 ZIP과 기존 운영 데이터는 그대로이며, 여기에는 가명과 운영 ID 자리표시자만 포함합니다. 코드만 복원하면 운영 JSON·ScriptProperties·권한·트리거까지 복원되는 것은 아닙니다. 이 번호는 보관용 번호입니다.
