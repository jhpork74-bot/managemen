# v4.4.22 CSFS 월별 게시판·회사 사진·상단 버튼 정렬

상태: **로컬·모의 검증 / 운영 설치 점검 중**

[설치 및 데이터 호환성](CSFS_설치안내.md)

등록 시 선택 월 기준의 카드 게시판, 입력란 한 개씩 추가/삭제, 수정/삭제, 회사 Drive 사진 저장을 전용 HTML/GS로 분리했습니다. 잔디 확인 후 재전송과 상단 버튼 정렬을 포함하는 일관된 전체 복구용 세트입니다. v4.4.20·21 폴더 자체는 공개하지 않습니다.

최신 설치 로그에서 회사 폴더 ID 등록과 조회는 정상이었지만 운영 공통 사진 스크립트가 이전 버전으로 확인됐습니다. 최신 RepairPhotoStorage.gs 교체 및 기존 배포 갱신 안내까지 제공했으며, 이후 실제 CSFS 업로드 성공은 확인 전입니다. 실제 잔디 달력 이미지 미리보기·모바일 카메라도 미확인입니다.

## 공개 보관 사본의 설정

실제 직원 이름·원본 시트 ID·회사 Drive 폴더 ID는 가명과 자리표시자로 바꿨습니다. 설치 시 기존 운영 시트 ID와 실제 회사 폴더 ID를 복원해야 합니다. ScriptProperties·사진 원본·운영 JSON·권한·트리거는 이 보관본에 포함되지 않습니다. CSFS_FOLDER_PLACEHOLDER는 실제 폴더가 아닙니다. 사진 확인키는 기존 속성 백업을 별도로 보존하세요.
