# v4.4.7 당직 전용 파일 분리·공통 대체 순번·중복 작성 방지

상태: **로컬 검증 / 운영 확인 전**

- 당직 계산·서비스·화면을 DutyRosterCore.gs, DutyManagement.gs, DutyManagementUI.html로 분리했습니다.
- 공통 저장·잠금은 FacilityStorage.gs로 분리하고 보고 시트 작성 중에는 원본 잠금을 유지하지 않습니다.
- 한 번 클릭하면 작성과 서버 새로고침이 끝날 때까지 버튼을 비활성화하고 성공·실패 후 다시 활성화합니다.
- 직원 등록창은 선택한 장소별로 표시합니다.
- 분관 두 대상자는 날짜순으로 합친 공통 후보 순번을 사용하며 후보를 체크로 고를 수 있습니다. 후보 변경 시 일반 당직자를 유지하고 점심대체만 재계산합니다.
- 조회 월 전체삭제·취소와 자동 재생성 방지를 포함합니다.

[여섯 파일 적용 방법과 기능 안내](분리설치안내.md)

Index와 DutyManagementUI는 HTML입니다. Code, FacilityStorage, DutyRosterCore, DutyManagement는 스크립트입니다. 기존 세 파일을 교체하고 새 세 파일을 추가하는 구조 변경입니다. Code의 기존 SPREADSHEET_ID를 유지하세요. 이 GitHub 사본에는 실제 운영 ID 대신 자리표시자만 있습니다.

기존 원본과 운영 자료에 실제 삭제·배포를 수행하지 않았습니다. 운영 자료·서버 속성·권한·트리거는 별도입니다. 이 번호는 보관용 번호입니다.
