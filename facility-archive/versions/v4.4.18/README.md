# v4.4.18 고장·공사 사진 Drive 저장

로컬·모의 Sheets/Drive/서버·Edge 검증 완료 / 실제 운영 적용 전.

[설치 및 사용](고장공사사진_Drive_설치안내.md)

고장 사진 및 공사 전/중/후 새 사진은 지정 Drive 폴더로 업로드하고 업무 JSON에는 서명된 연결을 저장합니다. 기존 내장 사진은 보존합니다. 별도 폴더 미지정 시 잔디 달력 폴더를 사용합니다. 새 사진은 공개 공유하지 않습니다. JSON 백업만으로 사진 파일은 복구되지 않으며 Drive 파일과 ScriptProperties의 사진 확인키를 별도 보존해야 합니다. 공개 시트 ID는 자리표시자입니다.
