초기 보관 번호는 2026-10-27에 정리했으며 이후 개발 버전을 추가합니다. 이전 배포 날짜·번호를 임의로 복원하지 않았습니다. 사용자께서 확인한 월 당직표 기능은 v4.4.3에 해당하는 구성입니다. 사용자 확인 상태는 위 표와 VERSIONS.json에 기록합니다.

## 되돌리는 방법

1. 현재 코드와 전체 JSON, 시트 사본을 먼저 보관합니다.
2. 원하는 versions 폴더의 README를 읽고 그 폴더의 파일 세트를 사용합니다.
3. Code.gs의 스프레드시트 ID 자리표시자를 기존 본인 ID로 바꿉니다.
4. Index.html은 HTML 파일 Index에 붙입니다. Code.gs에 붙이면 Unexpected token '<' 오류가 납니다.
5. 별도 테스트 프로젝트에서 데이터 호환성을 확인한 뒤 기존 웹앱을 새 버전으로 배포합니다.

Google Apps Script의 ScriptProperties(API키·트리거·알림 캘린더 ID 등)는 GitHub 소스에 포함되지 않습니다. 새 프로젝트 복구 시 필요한 속성과 권한을 다시 설정해야 합니다. 이 저장소는 운영 JSON·사진·API키·직원 명부 백업을 대신하지 않습니다.

## 시험

Node.js가 있으면 저장소 루트에서 node verify-archive.cjs를 실행합니다. GS/HTML 구문과 각 버전의 자체 포함 모의 서버·순번 시험을 검사합니다. 브라우저·실제 Google 권한·휴대전화 알림 시험은 포함하지 않습니다.

## 보관 상태

검증 결과는 VALIDATION.json, 파일 해시는 SHA256SUMS.json, 버전 목록은 VERSIONS.json에 있습니다. tests는 가명과 모의 서비스를 사용합니다. 원본 파일은 변경하지 않았으며 공개 저장소에 보관하는 사본에서 직원 실명과 실제 운영 식별 정보를 제거했습니다. GitHub 저장 여부는 원격 파일 목록과 커밋으로 확인합니다.
